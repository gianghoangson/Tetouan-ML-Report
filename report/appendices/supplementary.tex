\subsection{Reproducibility}
All results come from the project repository. \code{python run_all.py} runs the whole pipeline in order and regenerates every result table and figure; \code{TETOUAN_N_JOBS} sets the number of CPU threads and changes speed only. Results are reproducible because library versions are pinned (\cref{tab:dependencies}, Python 3.12), every model and search uses seed 42, and the split is defined by fixed dates. Only the timing columns change between runs.
