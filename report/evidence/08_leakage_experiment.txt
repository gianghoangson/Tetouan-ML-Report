## 2. Four set-ups S1–S4 (same Random Forest)

| Set-up | Data | Split | Features | Mimics |
|---|---|---|---|---|
| S1 | 10-min | shuffled 75/25 | weather + P1-style calendar (with `dayofyear`) | P1 and typical Kaggle notebooks |
| S2 | 10-min | shuffled 75/25 | S1 + 10-minute lag | Kaggle with a lag |
| S3 | 10-min | chronological, test = December | S1 without `dayofyear` + 10-minute lag | Correct split, 10-minute horizon |
| S4 | hourly | chronological, test = December | feature set D, day-ahead | **This project** |

With a shuffled split a test point at 20:10 has its neighbours at 20:00 and 20:20 in the training set: the model only has to **interpolate**, which inflates R².

**10-minute features** (P1-style calendar, weather, previous 10-minute load):

    # Calendar features used in the original benchmark (P1), including absolute-time ones
    return pd.DataFrame({'month': idx.month, 'day': idx.day, 'hour': idx.hour, 'minute': idx.minute,
                         'dayofyear': idx.dayofyear, 'weekofyear': idx.isocalendar().week.to_numpy(),

## 3. T12b – Tuning with shuffled KFold vs TimeSeriesSplit

Tune the same RF twice on the development set (day-ahead), changing only the folds; record the CV estimate, the best parameters and the real test RMSE. `optimism_%` = test RMSE / CV RMSE − 1 (positive = CV over-promises).

--- CELL 17 (code; execution=7) ---
est, space, n_iter = search_spaces(n_jobs=1)['RF']
n_iter = min(n_iter, 20)
Xd, yd, Xt, yt = X[dev][MF], y[dev], X[te][MF], y[te]
rows = []
for name, cv in [('KFold (shuffled)', KFold(5, shuffle=True, random_state=RANDOM_STATE)),
                 ('TimeSeriesSplit', make_tscv())]:
    search = RandomizedSearchCV(est, space, n_iter=n_iter, cv=cv, scoring='neg_root_mean_squared_error',
                                refit=True, random_state=RANDOM_STATE, n_jobs=N_JOBS)
    t0 = time.time()
    search.fit(Xd, yd)
    test_rmse = metrics(yt, search.best_estimator_.predict(Xt))['RMSE']
    rows.append({'cv_method': name, 'cv_RMSE_estimate': -search.best_score_, 'test_RMSE': test_rmse,
                 'optimism_%': 100 * (test_rmse / -search.best_score_ - 1),
                 'best_params': json.dumps({k: (v.item() if hasattr(v, 'item') else v)
                                            for k, v in search.best_params_.items()}),
                 'time_s': time.time() - t0})
    print(f'{name}: {time.time() - t0:.1f}s')
t12b = pd.DataFrame(rows).set_index('cv_method')
t12b.to_csv(TABLES / 'T12b_kfold_vs_tscv.csv')

## 4. Summary

- With the same model, shuffling the data or shortening the horizon lifts R² from 0.98 to 0.999: most of the high scores online come from the **evaluation**, not from the model.
- Shuffled KFold for tuning both over-promises and selects a worse model than TimeSeriesSplit.
- This project's R² is lower than many online notebooks, but it is the **trustworthy** number for the real task (forecasting the next day).
