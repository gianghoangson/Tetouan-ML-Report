# 03 – Naive baselines (Level 0) and default models (Level 1)

Guideline sections 6–7, day-ahead problem (h24).

- **Level 0:** naive baselines, the minimum any model must beat.
- **Level 1:** the five models with **default** hyperparameters, trained on January–October and evaluated on November, on feature set D.

**Checkpoint:** if no model beats Naive-24h, go back to the features before tuning. Outputs: **T04**, **F11**, **F11b**.

## 1. Level 0 – Naive baselines

| Baseline | Formula | Meaning |
|---|---|---|
| Naive-24h | ŷ(t) = y(t−24) | Tomorrow looks like today |
| Naive-168h | ŷ(t) = y(t−168) | Same hour, same weekday last week |
| MeanProfile | mean of the training load for the same (hour, weekday) | A "typical week", no recent history |

The baselines are sklearn-style estimators (`src/models.py`), so Level 2 can cross-validate them exactly like the models.

## 2. Level 1 – Five models with default hyperparameters

Fit each model on the training months and record the error on training and validation data (`fit_time` in seconds). LR and SVR scale their inputs inside a `Pipeline`, so the scaler only sees training data; SVR also scales the **target** (`TransformedTargetRegressor`), otherwise its default `epsilon=0.1` is meaningless for a load of about 70,000 kW. Tree models need no scaling.

--- CELL 9 (code; execution=4) ---
models = default_models()
for name in MODEL_NAMES:

## 3. T04 – Level 0 and Level 1 results

Save the long table (standard result columns), then build a wide table with one row per model, the skill score against Naive-24h (`1 − RMSE / RMSE_Naive-24h`) and the overfitting ratio (`RMSE_val / RMSE_train`; `inf` means zero training error).

--- CELL 13 (code; execution=6) ---
long = save_results(TABLES / 'T04_level0_level1.csv')   # long format, standard columns

wide = long.pivot_table(index=['level', 'model'], columns='split', values=['RMSE', 'MAE', 'MAPE', 'R2'])
wide.columns = [f'{split}_{m}' for m, split in wide.columns]
wide = wide[[f'{s}_{m}' for s in ('val', 'train') for m in ('RMSE', 'MAE', 'MAPE', 'R2')]]
wide['fit_time_s'] = long.groupby(['level', 'model'])['fit_time'].first()
naive_rmse = wide.loc[('L0', 'Naive-24h'), 'val_RMSE']
wide['skill_vs_naive24'] = 1 - wide['val_RMSE'] / naive_rmse       # > 0 = better than Naive-24h
# >> 1 = overfitting; inf = training RMSE < 1 kW, i.e. the model memorised the training set
wide['overfit_ratio'] = (wide['val_RMSE'] / wide['train_RMSE'].where(wide['train_RMSE'] >= 1)).fillna(np.inf)
wide = wide.sort_values('val_RMSE')
wide.to_csv(TABLES / 'T04_level0_level1_wide.csv')
