raw = pd.read_csv(ROOT / 'data' / 'raw' / 'Tetuan City power consumption.csv')

def longest_constant_run(s):
    return s.groupby((s != s.shift()).cumsum()).size().max()

quality = pd.Series({
    'Rows (10-min)': len(df),

## 4. Summary and consequences for feature engineering

| Finding | Evidence | Consequence |
|---|---|---|
| Clean data | Section 2, T01 | No deletion or imputation; hourly resampling only |
| Very strong daily cycle | F03, F07 (lag 24 = 0.98) | `hour`, `hour_sin/cos`, `lag_24`, `lag_48`; Naive-24h is a hard baseline |
| Weekly cycle | F04, F07 (lag 168 = 0.95) | `dayofweek`, `is_weekend` |
| Sundays −6%, Sunday mornings −15% | F04, F08 | Weekday effect interacts with the hour |
| Religious holidays about −9%, civil holidays about −3% (uneven) | F08 | Separate `is_religious_holiday` and `is_civil_holiday` |
| Ramadan reshapes the night profile | F05 | `is_ramadan` |
| Summer +30%, non-linear in temperature | F01, F03, F06a | Non-linear models; no `month` feature (December is unseen in training) |
| Load transfers between zones | DQ01, F02 | Target = total; same-time zones are not features |
| Near-binary wind speed | DQ02 | Kept, reported as a limitation |
