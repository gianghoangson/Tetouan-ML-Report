# 06 – Ablation study and forecast horizon

Guideline section 10.

**Ablation (RQ2): how much does each feature group contribute?** Feature groups are added one at a time (A → E), with the Level 3 hyperparameters kept fixed and the same five folds. RF and XGB are used, as suggested by the guideline, plus their relative versions on the sets that contain `lag_24` (D, E, F).

| Set | Features | Question |
|---|---|---|
| A | Weather | How far does weather alone go? |
| B | A + calendar | What do hour and weekday add? |
| C | B + special days | Do holidays and Ramadan help? |
| D | C + `lag_24`, `lag_48` | Most recent days |
| E | D + `lag_168` + rolling means (full set) | Last week and recent level |
| F | E without weather | How much do models rely on the (perfect) weather forecast? |

**Secondary problem h1 (1 hour ahead):** tuned separately with exactly the Level 3 procedure (both target types). It shows how much harder the day-ahead problem is and gives a number comparable with the literature; its December result is computed in notebook 07. Outputs: **T09**, **F15**, **T10**, **F15b**, `best_params_h1.json`.

## 3. Horizon: 1 hour (h1) vs 24 hours (h24)

- h1 models use the matching set: weather, calendar, special days, `lag_1..3`, `lag_24` (`MODEL_FEATURES[1]`).
- **Separate tuning for h1**, same search spaces and budgets as Level 3, both target types. The relative h1 version learns `y − lag_1` ("next hour minus this hour"); `lag_1` beat `lag_24` on dev CV for three of four non-linear models.
- h1 adds the **Persistence** baseline: ŷ(t) = y(t−1).
- `TimeSeriesSplit` counts folds from the end, so the five validation windows are identical for both horizons (asserted below).

## 6. Summary

- **Daily lags are by far the most important feature group** (about −65% error). Calendar and special days help. `lag_168` and the rolling means hurt by aggravating the extrapolation problem, hence feature set D.
- Weather contributes little once lags are present, so the perfect-weather assumption makes the results only slightly optimistic.
- Secondary problem h1 (tuned separately): SVR reaches a CV MAPE of 1.86%.
