# 05 – Level 3: hyperparameter tuning

Guideline section 9. How much does tuning improve on the defaults?

- `RandomizedSearchCV` on **the same five folds** as Level 2, so the Level 2 → Level 3 difference is the effect of tuning. Selection criterion: lowest mean CV RMSE.
- LR is tuned as **Ridge** (L2 penalty `alpha`), since plain LR has no hyperparameter.
- **Two target types per model:** *absolute* (learn `y`) and *relative* (`<model>_delta`: learn `y − lag_24`, then add `lag_24` back). Level 2 showed that tree models cannot extrapolate when July loads exceed everything seen in training, whereas the deviation from yesterday stays in a familiar range. `lag_24` was chosen as the base on dev CV (`lag_168` was much worse). Both types use the same search space; the better one is chosen on CV.
- Searches run in parallel (`n_jobs=N_JOBS`) with single-threaded inner models; no refit here (notebook 07 refits).

**Caveat:** hyperparameters are chosen on the same folds that are reported, so Level 3 scores are slightly optimistic (selection bias); notebook 07 re-measures on December. Outputs: **T06**, **T07**, **F13**, **F14**, `best_params.json`.

## 1. T06a – Search space

Readable description of each distribution: `loguniform(a, b)` samples evenly on a log scale, `integer a … b` is `randint`, `uniform(a, b)` covers [a, b]. The relative versions use the same space with a `regressor__` prefix.

--- CELL 6 (code; execution=3) ---
def describe(dist):
    if isinstance(dist, list):
        return ', '.join(str(v) for v in dist)
    name, args = dist.dist.name, dist.args
    if name == 'uniform':                       # scipy uniform(loc, scale) covers [loc, loc + scale]
        return f'uniform({args[0]}, {args[0] + args[1]})'
    if name == 'randint':                       # randint(low, high) covers low … high − 1
        return f'integer {args[0]} … {args[1] - 1}'
    return f'{name}({", ".join(str(a) for a in args)})'

## 2. Randomized search with TimeSeriesSplit

For each model and target type: sample `n_iter` configurations, score each on the five folds with the four metrics, keep the configuration with the best mean RMSE, log its per-fold results and store its parameters. Every search uses the same `random_state`, so the absolute and relative versions try the same configurations.

## 6. F14 – Sensitivity to one key hyperparameter

Each dot is a sampled configuration (other hyperparameters vary at random); orange = best. Panels show the better target type of each model; log-scaled parameters are plotted on a log axis.

--- CELL 21 (code; execution=9) ---
KEY = {'LR': ('ridge__alpha', True), 'DT': ('max_depth', False), 'RF': ('max_features', False),
       'SVR': ('regressor__svr__C', True), 'XGB': ('learning_rate', True)}

def plot_sensitivity(ax, res, param, log):
    vals, rmse = res[f'param_{param}'], -res['mean_test_RMSE']
    num = pd.to_numeric(vals, errors='coerce')
    if num.notna().all():
        xs = num.astype(float)
        if log:   # plot log10(value) on a linear axis, label ticks with the original value
            xs = np.log10(xs)
            ax.xaxis.set_major_locator(plt.MaxNLocator(4))
            ax.xaxis.set_major_formatter(plt.FuncFormatter(lambda v, _: f'{10 ** v:.3g}'))
    else:   # categorical, e.g. max_depth with None or max_features with 'sqrt'
        labels = vals.astype(str)
        def order(v):   # numbers first (ascending), then text values such as 'None' or 'sqrt'
            n = pd.to_numeric(v, errors='coerce')
            return (0, n, '') if pd.notna(n) else (1, 0.0, v)
        cats = sorted(labels.unique(), key=order)
        jitter = np.random.default_rng(0).uniform(-0.12, 0.12, len(labels))
        xs = labels.map({c: i for i, c in enumerate(cats)}).astype(float) + jitter
        ax.set_xticks(range(len(cats)), cats)
