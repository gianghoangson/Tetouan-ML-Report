\section{Related Work}\label{sec:related}
\textbf{Baselines and models.} A seasonal naive forecast repeats the load of the same hour one day or one week earlier; it measures how much information the demand cycle already contains. Regression models map calendar, weather and past-load predictors to the load: linear regression is a low-complexity reference, decision trees learn threshold interactions, random forests average randomised trees, XGBoost adds sequentially fitted trees\cite{chen2016}, and RBF support vector regression offers a smooth nonlinear alternative.

\textbf{Tetouan studies.} \Cref{tab:literature} summarises six studies on this dataset, as reported in the course literature review. Salam and El Hibaoui\cite{salam2018} give the original conventional-ML comparison; later work studies optimised regression trees\cite{rose2023}, recurrent networks with a December holdout\cite{silva2023}, Prophet-based models\cite{islam2025}, lag-enriched neural networks\cite{alsalem2025} and a multi-model Darts comparison\cite{biswas2026}. The studies differ in target (one zone, the mean or the sum of zones), resolution, horizon and split, so their numbers are not a common benchmark and this report makes no ranking against them.

\textbf{Validation and leakage.} Time-series validation keeps training data before validation data; the expanding-window scheme used here follows \code{TimeSeriesSplit}\cite{tscv}. Random search samples a fixed budget of hyperparameter configurations\cite{bergstra2012}. Leakage means using information that would not be available when the forecast is issued, for example fitting a scaler on test data or using same-time zone loads as inputs. Keeping fitted transformations inside a pipeline avoids the former\cite{pitfalls}.

\textbf{Public projects.} Ten public GitHub projects on this dataset were surveyed by reading their code (\cref{tab:survey}). Seven shuffle the data before splitting, many use \code{month} or \code{dayofyear}, one uses the other zones at the same timestamp as inputs, and none addresses day-ahead forecasting. \Cref{sec:leakage} measures how such choices change the reported accuracy.
